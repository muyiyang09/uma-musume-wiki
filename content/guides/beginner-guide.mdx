## 欢迎来到赛马娘的世界

**赛马娘 Pretty Derby（ウマ娘 プリティーダービー）**是 Cygames 开发的一款养成模拟类手游。你将扮演训练员，培养赛马娘参加比赛，目标是拿下各种 G1 赛事冠军。

---

## 基础概念速览

| 概念 | 说明 |
|------|------|
| **育成** | 一次完整的培养周期，约 30~78 回合，每回合可选择训练/休息/比赛 |
| **因子** | 育成结束后继承的属性/技能/适性加成，是长期养成核心 |
| **支援卡** | 6 张编入卡组，决定训练效果和可获取技能 |
| **适性** | 场地(芝/ダート) × 距离(短/マイル/中/长) × 跑法(逃/先/差/追) |
| **URA / 青春杯 / 巅峰杯 / 大师杯** | 不同育成剧本，各有独特机制 |

## 首次育成流程

### 第一步：选择育成赛马娘

新手推荐优先级：
1. **特别周**（先行/中距离，属性均衡，固有好触发）
2. **无声铃鹿**（逃げ/中距离，速度极高，容易理解）
3. **东海帝王**（先行/差し/中距离，固有强力）

> 💡 **新手避坑**：不要一上来就养长距离马（如目白麦昆），长距离对耐力和配卡要求高，容易育成失败。

### 第二步：编成支援卡

初期没有 SSR 的话，用系统送的 SSR 和 SR 过渡。核心原则：
- **6 张卡中至少 2 张速度卡**
- 耐力卡至少 1 张（中长距离需要 2 张）
- 力量卡 / 根性卡补位
- 友人卡（绿色背景）强烈推荐带 1 张，可以回复体力和降低失败率

### 第三步：育成中关键决策

**训练优先级**：
```
速度训练 > 力量训练 > 耐力训练（根据目标赛事调整）
```

**比赛选择**：
- 目标赛事必须参加且必须获胜
- 非目标赛事可选择性参加以获得粉丝数和技能点
- 粉丝数不够时优先补比赛

**体力管理**：
- 体力低于 50% 时失败率大幅上升 → 必须休息
- 体力 70% 以上是训练黄金区间
- 夏季合宿期训练效果 1.5 倍，提前攒满体力

## 新手常见问题

| 问题 | 答案 |
|------|------|
| 为什么我的马总是输？ | 检查适性是否匹配赛事要求，属性是否达标 |
| SSR 支援卡重要吗？ | 重要但非必须，配卡逻辑比单卡强度重要 |
| 因子怎么刷？ | 反复育成同一匹马，利用继承系统 |
| 体力不够怎么办？ | 带友人卡、合理安排休息、利用事件回复 |
