## 什么是因子

每次育成结束后，系统会根据该次育成的结果生成**因子（Factor）**。将带因子的赛马娘设为**种马（父母）**，新育成时父母的部分因子会被继承到下一代，长期积累可大幅提升育成上限。

---

## 四种因子详解

### 蓝色因子（属性因子）

| 属性 | 获得条件 | 星数上限 |
|------|----------|:---:|
| 速度因子 | 最终速度 ≥ 600 | ★★★ |
| 耐力因子 | 最终耐力 ≥ 600 | ★★★ |
| 力量因子 | 最终力量 ≥ 600 | ★★★ |
| 根性因子 | 最终根性 ≥ 600 | ★★★ |
| 智力因子 | 最终智力 ≥ 600 | ★★★ |

| 属性值 | 星级 |
|--------|:---:|
| 600~799 | ★ |
| 800~999 | ★★ |
| 1000~1099 | ★★ |
| 1100+ | ★★★ |

> 💡 **刷蓝因子目标**：1100+ 单属性出 ★★★，双属性 1100+ 出双 ★★★ 是优质种马标配。

### 红色因子（适性因子）

育成中获胜过的 **G1 赛事** 会生成对应的适性因子。继承后提升对应适性等级（最高 S）。

| 适性 | 说明 |
|------|------|
| 芝 / ダート | 场地适性 |
| 短 / 英里 / 中 / 长 | 距离适性 |
| 逃 / 先 / 差 / 追 | 跑法适性 |

**重点**：适性从 A → S 的收益巨大，适性 S 时属性加成更高、技能发动率提升。

### 绿色因子（固有技能等级因子）

育成结束时固有技能达到 Lv.6 即可获得。继承后可提升新马娘的固有技能初始等级。

### 白色因子（技能因子）

育成中获取的技能有小概率生成对应的白色因子。继承后育成开始时直接获得该技能。

---

## 继承规则

### 继承时点
- 育成开始时：首次继承
- 经典级 4 月前半：第二次继承（继承更多因子）
- シニア級 4 月前半：第三次继承

### 继承概率

| 因子类型 | 继承概率 | 备注 |
|----------|:---:|------|
| 蓝因子 ★ | 高 | 几乎必定继承 |
| 蓝因子 ★★ | 中 | 约 70% |
| 蓝因子 ★★★ | 较低 | 约 30%~50% |
| 红因子 | 中 | 固定概率 |
| 白因子 | 低 | 技能越稀有概率越低 |

## 刷因子实操流程

### 最短路线刷蓝因子（中距离马）

```
1. 选育成剧本：青春杯（因子获取效率高）
2. 因子继承：父母选双速度 ★★★
3. 训练重点：全程速度训练为主，其他属性满足目标赛事即可
4. 目标：育成结束速度 ≥ 1100
5. 重复育成直到出速度 ★★★
```

### 优质种马标准

| 等级 | 要求 |
|:---:|------|
| 可用 | 单属性 ★★★ |
| 良 | 双属性 ★★★ + 任意红因子 |
| 优 | 双属性 ★★★ + 关键红因子（如中距离） |
| 极品 | 三属性 ★★★ + 关键红因子 + 实用白因子 |

---

## 因子相性

父母之间如果有多场共同获胜的 G1 赛事，**相性值**会提高。高相性提升继承概率和因子效果。

提升相性的方法：
- 让父母分别多跑 G1 赛事并获胜
- 使用同战术/同距离的赛马娘组合

## 常见问题

| 问题 | 答案 |
|------|------|
| 因子能遗传几代？ | 只继承父母一代，不隔代 |
| 红因子能提升适性到 S 吗？ | 可以，但需要符合特定条件 |
| 白因子值得刻意刷吗？ | 不推荐，概率太低，随缘即可 |
| 青春杯刷因子比 URA 好吗？ | 是的，青春杯奖励机制更利于刷属性 |
