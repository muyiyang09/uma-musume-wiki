欢迎来到赛马娘的世界

赛马娘 Pretty Derby（ウマ娘 プリティーダービー）是 Cygames 开发的一款养成模拟类手游。你将扮演训练员，培养赛马娘参加比赛，目标是拿下各种 G1 赛事冠军。

基础概念速览

概念说明 育成一次完整的培养周期，约 30~78 回合，每回合可选择训练/休息/比赛 因子育成结束后继承的属性/技能/适性加成，是长期养成核心 支援卡6 张编入卡组，决定训练效果和可获取技能 适性场地(芝/ダート) × 距离(短/マイル/中/长) × 跑法(逃/先/差/追) URA / 青春杯 / 巅峰杯 / 大师杯不同育成剧本，各有独特机制

首次育成流程

第一步：选择育成赛马娘

新手推荐优先级：

  • 特别周（先行/中距离，属性均衡，固有好触发）
  • 无声铃鹿（逃げ/中距离，速度极高，容易理解）
  • 东海帝王（先行/差し/中距离，固有强力）
    • 💡 新手避坑：不要一上来就养长距离马（如目白麦昆），长距离对耐力和配卡要求高，容易育成失败。
