Beyond Dreams 概述

Beyond Dreams（ビヨンドドリーム） 是 2026 年 2 月 24 日上线的第 13 个育成剧本，以ブリダーズカップ（Breeders' Cup）和海外远征为舞台。
核心机制：チームランク（团队等级） 驱动的新育成模式，与以往剧本完全不同。

基础属性上限

速度耐力力量根性智力 +900+500+500+500+600

总上限高达 +3000，全剧本最高。

核心机制：メンバー（队员）系统

チームランク

育成中有 3 名メンバー，她们的最低等级决定团队等级。团队等级越高 → Dreams 训练效果越强。

``

メンバーA Lv.5 + メンバーB Lv.3 + メンバーC Lv.4 → チームランク = Lv.3（最低值）

``

所以必须均衡提升所有メンバー。

Dreams 训练 (DREAMS トレーニング)

编成支援卡 5 种类以上时，Dreams 训练触发额外效果。推荐ハイランダー编成（5种各1张+1张自由位）。

支援卡编成

关键卡：SSR カジノドライヴ

状态Dreams ポイント获取量 未编成5 R 编成8 SSR 编成10 SSR カジノドライヴ基本必带，即使是 0 破也比 R 版强。

育成流程与关键决策

前期（出道~经典级）

阶段行动备注 序盘DP 优先升メンタル到 Lv.3メンタル影响训练效率 基础育成训练为主，均衡提升メンバー不急于比赛

中期（经典级~シニア級前半）

阶段行动 合宿前攒满体力 + 调整メンバー等级均衡 夏季合宿DREAMS 训练集中使用，最大化收益 远征期BC 赛事必须全部获胜

后期（シニア級后半）

阶段行动 冲刺期ゲージMAX + 友情训练组合，爆发属性成长 シニア合宿4 次训练在 11 月前半前用完

常见翻车原因

翻车原因对策 某个メンバー等级掉队优先去该メンバー出现的设施训练 ハイランダー编成失败确保 5 种类型各至少 1 张 カジノドライヴ未带必带，点数差一倍 DP 分配错误优先メンタル Lv.3 → 再升其他 合宿浪费提前攒满 DP + 体力，4 次训练都用 DREAMS
