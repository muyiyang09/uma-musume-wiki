什么是因子

每次育成结束后，系统会根据该次育成的结果生成因子（Factor）。将带因子的赛马娘设为种马（父母），新育成时父母的部分因子会被继承到下一代，长期积累可大幅提升育成上限。

四种因子详解

蓝色因子（属性因子）

属性获得条件星数上限 速度因子最终速度 ≥ 600★★★ 耐力因子最终耐力 ≥ 600★★★ 力量因子最终力量 ≥ 600★★★ 根性因子最终根性 ≥ 600★★★ 智力因子最终智力 ≥ 600★★★ 属性值星级 600~799★ 800~999★★ 1000~1099★★ 1100+★★★
💡 刷蓝因子目标：1100+ 单属性出 ★★★，双属性 1100+ 出双 ★★★ 是优质种马标配。

红色因子（适性因子）

育成中获胜过的 G1 赛事 会生成对应的适性因子。继承后提升对应适性等级（最高 S）。

适性说明 芝 / ダート场地适性 短 / 英里 / 中 / 长距离适性 逃 / 先 / 差 / 追跑法适性 重点：适性从 A → S 的收益巨大，适性 S 时属性加成更高、技能发动率提升。

绿色因子（固有技能等级因子）

育成结束时固有技能达到 Lv.6 即可获得。继承后可提升新马娘的固有技能初始等级。

白色因子（技能因子）

育成中获取的技能有小概率生成对应的白色因子。继承后育成开始时直接获得该技能。

刷因子实操流程

最短路线刷蓝因子（中距离马）

``

  1. 选育成剧本：青春杯（因子获取效率高）
  2. 因子继承：父母选双速度 ★★★
  3. 训练重点：全程速度训练为主，其他属性满足目标赛事即可
  4. 目标：育成结束速度 ≥ 1100
  5. 重复育成直到出速度 ★★★

``

优质种马标准

等级要求 可用单属性 ★★★ 良双属性 ★★★ + 任意红因子 优双属性 ★★★ + 关键红因子（如中距离） 极品三属性 ★★★ + 关键红因子 + 实用白因子

因子相性

父母之间如果有多场共同获胜的 G1 赛事，相性值会提高。高相性提升继承概率和因子效果。
