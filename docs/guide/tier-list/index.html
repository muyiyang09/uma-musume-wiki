S 级（类型核心）

支援卡类型核心技能评价 ミホノブルボン SSR耐力鋼の意志长距离耐力卡第一名，天皇赏春/菊花赏等长距离赛事必备 ゴールドシップ SSR根性不屈の心差し/追込泛用根性卡，根性属性含金量高 メジロラモーヌ SSR力量パワーボム力量卡首选，中距离育成必带
